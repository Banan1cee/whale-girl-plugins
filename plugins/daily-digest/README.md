# 日报便签（daily-digest）

- 等级：**2 级 · 受限 Wasm**
- 入口：`plugin.wasm`
- provides：`tool.run@1`（manual / tool）
- calls：无
- 数据访问：无；不联网、不读写文件
- 最低客户端：4.3.0

## 行为

宿主把「消息汇总」生成的日报文本作为 `tool.run@1` 输入交给 Wasm；插件做纯文本整理后返回 JSON 字符串：标题变 `【】`、列表变 `·`、去掉行首 Markdown 符号、压掉多余空行。它不读取聊天记录，也不能自己调模型。

## 与迁移前的差异

- 迁移前由宿主在旧动作契约里生成汇总并调用工具；新协议没有该宿主动作，改为用户先在宿主生成汇总，再把文本作为 `tool.run@1` 输入。
- 输入输出从旧的展示结果变成 `tool.run@1` 的 JSON 文本；2 级工具纯文本返回不再被误当 JSON 解析（依赖运行时的 2 级修复）。
- 无新增权限；不联网、不读写文件。
