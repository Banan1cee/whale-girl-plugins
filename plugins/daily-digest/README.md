# 日报便签（daily-digest）

把「消息汇总」生成的 Markdown 日报整理成**可直接粘贴**的纯文本：标题变`【】`、列表变`·`、去掉 `#`/`**`、压掉多余空行。

适合把日报粘到微信群、备忘录或待办 App —— 那些地方不渲染 Markdown，`## 重要的事` 会变成一串井号。

## 为什么是 Api 2

插件拿不到聊天记录、也不能自己调模型。Api 2 的 `HostAction: chat.summary` 由宿主完成这两件事：

1. 用户点「生成汇总」，选今天或昨天并确认；
2. 鲸鲸读本机该日期的群聊/私聊片段，交给当前模型生成日报；
3. **插件只收到生成后的文本**，加工后把结果交回宿主展示。

所以这个插件不需要网络、文件、微信接口，也不接触任何密钥——和规范第 3 条一致。

## 输入输出契约

| 项 | 值 |
| --- | --- |
| 导入 | `whale.input_size() -> i32`、`whale.input_byte(i) -> i32`、`whale.output_byte(v)` |
| 导出 | `run() -> i32`，返回 `0` 表示成功 |
| 输入 | 汇总后的日报文本（UTF-8，≤ 64 KiB） |
| 输出 | 整理后的纯文本（UTF-8，≤ 64 KiB） |
| 限制 | 无线性内存、无网络、无文件；宿主 3 秒超时 |

## 行为

| 输入 | 输出 |
| --- | --- |
| `## 一句话总结` | `【一句话总结】` |
| `- 摸鱼群：聊了加班` | `· 摸鱼群：聊了加班` |
| `**周五交周报**` | `周五交周报` |
| 连续空行 | 压成一行 |
| 行尾空格 | 去掉 |
| 正文里的 `#` | 原样保留（只处理行首） |

示例：

```
# 全局日报 · 2026-11-10      →   【全局日报 · 2026-11-10】
## 重要的事                  →   【重要的事】
- 摸鱼群：聊了加班           →   · 摸鱼群：聊了加班
- **周报**                   →   · 周报
```

## 构建

本仓库不带 wasm 工具链依赖；`src/wasm.js` 直接生成字节码。

```bash
node build.js        # 产出 ../../packages/daily-digest-1.0.0.zip 并更新 ../../index-v2.json
node test/test.js    # 契约测试
```

- `src/reference.js`：同一套规则的 JS 实现，作为**标准答案**；
- `src/wasm.js`：手写字节码生成器 + 按宿主 Runner 契约运行的模拟器；
- `test/test.js`：26 个样例 + 1 个接近 64 KiB 的输入 + 300 组随机差分，要求 WASM 与参考实现**逐字节一致**；
- 打包固定时间戳，同一份源码重复构建得到相同 SHA-256（可复现）。

当前产物：`plugin.wasm` 505 字节，ZIP 1126 字节。

## 试装

1. 「插件市场 → 从本地安装」选 `packages/daily-digest-1.0.0.zip`；
2. 启动器会提示「本地 ZIP 未经市场审核」，确认后安装；
3. 在「已安装」卡片点「设置」→ 选今天/昨天 → 生成汇总 → 确认权限提示；
4. 插件收到汇总文本，输出整理后的便签，可复制。

## 已知限制

- 只做排版，不提炼内容（提炼由宿主的汇总模型完成）；
- 输出上限 64 KiB、运行上限 3 秒；
- 需要 ≥ 4.1.0 且带 Api 2 的客户端；客户端未发布前只能本地试装，不能公开上架。
