# 上下文便签（context-notes）

Api 3 消息插件，管两个环节：

**① 回复前**（`chat.prompt`）读最近 12 条会话，再用自己的 `state` 累计跨轮信息，在系统提示词末尾补一张便签：

```
【本轮上下文】群聊｜最近 12 条里有 2 人在说话｜对方连发 3 条｜这位今天已经第 4 次找你｜
上一句在 1 秒前（节奏快）｜对方最后一句：「人呢」｜你上一条：「在」｜
还没回答的问题：「插件好了没？」｜本次会话累计第 24 轮｜别重复上一句的句式。
```

**② 发送前**（`chat.before_send`）整形：去掉 Markdown 痕迹、把换行和连续空白压成一个空格、拦住跑飞的长回复。

```
## 小结            →  小结 重点是：别熬夜。
**重点**是：别熬夜。

（1159 字的凑字回复）  →  截到最近的句末，最多 120 / 180 字
```

## 接口

| 项 | 值 |
| --- | --- |
| `Api` / `Kind` | `3` / `"message"` |
| `Hooks` | `chat.prompt`、`chat.before_send` |
| `Permissions` | `chat.history`（读最近 12 条）、`model.prompt`（读并替换本轮系统提示词） |
| 导入 | 只有 `whale.input_size` / `whale.input_byte` / `whale.output_byte` |
| 体积 | wasm 约 12.7 KB |
| 状态 | 每会话一个 state 文件，最大 16 KiB |

## 读到的上下文

| 来源 | 内容 |
| --- | --- |
| `history`（12 条） | 群聊/私聊、发言人数量、连发条数、对方最后一句、自己上一条、最后一条机器人回复之后悬着的问句、消息间隔 |
| `state`（跨轮） | 本次会话累计轮数、上一位发言人、同一人连续第几次找你、上次的时间戳、待回答问题 |

`state` 每轮整份替换，只留 `{n, at, top, topN, q}` 五个短字段，不囤聊天记录。

## 发送前的整形规则

1. 行首的 `#` `>` `-` `*` 一律去掉（标题、引用、列表）
2. 行内的 `*` `` ` `` `_` 去掉（强调、代码）
3. 换行、`\t`、连续空格压成一个空格
4. 超过上限就切在最近的 `。！？!?`；一个字都没有标点才硬截并补 `…`
5. 上限：群聊 120 字、私聊 180 字（宿主自己还会按标点拆成多条气泡，这里只兜住跑飞的情况）
6. 文本没变化就返回 `{}`，完全不动宿主的结果

## 构建

```bash
npm install
npx asc src/index.ts -O --runtime stub --noAssert --use abort=src/index/abortImpl -o plugin.wasm
```

`--use abort=src/index/abortImpl` 不能省：AssemblyScript 默认导入 `env.abort`，宿主只放行 `whale.*` 三条导入，多一条就整包 `invalid_import`。

另外宿主给 wasm 的内存只有 1 MiB（`--wasm-max-mem-pages=16`），**不能逐字符拼字符串**，否则 12 KB 的提示词就会把它撑爆、报 `invalid_output`。本插件一律按「引号位置 + substring」切片。

打包 ZIP 时根目录只放 `plugin.json` + `plugin.wasm`。

## 测试

```bash
node test/run.js
```

16 项：群聊连发、多人发言、未答问句、已答问句不提醒、私聊无历史、引号与反斜杠、超长截断、缺 `system` 降级、`state` 三轮累加、`state` 写回、Markdown 清理、干净短句不动、跑飞拦截、私聊上限、空白文本不动。

宿主级试装另有一份脚本，会真的启动 worker 进程、检查状态文件落盘，并跑一遍 `before_send`。

## 行为边界

- `chat.before_send` 不改语气，只改格式和长度；命令回复不经过这里（宿主自己跳过）
- `system` 缺失（未授权 `model.prompt`）时输出 `{}`
- 拼接后超过 15000 字就放弃改写，避免触碰宿主 16000 字上限
- 截断时同时避开 `\x` 转义和代理对，emoji 不会被切成两半
- 便签整体超过 220 字会再截一次

## 隐私

插件只能看到宿主给的那一份输入：当前消息、最近 12 条、上一条机器人回复、本轮回复文本、它自己写的 state。没有文件、网络、进程接口，拿不到密钥，也读不到别的会话。
