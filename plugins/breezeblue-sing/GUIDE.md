# Breezeblue 翻唱使用教程

## 1. 安装运行时和插件

1. 准备 Windows x64、微信 PC 4.2、支持 Api 4 的鲸鲸，以及兼容的 NVIDIA 显卡。先关掉鲸鲸，再下载并解压 [Windows 运行时 1.0.18](https://github.com/RacOrange/breezeblue-sing-installer/releases/tag/v1.0.18)。
2. 双击 `Setup.cmd`，按提示选择安装盘和鲸鲸目录。第一次下载语音模型和显卡依赖可能较久。已有运行时也可按这个流程升级。安装器会把插件一并写入所选鲸鲸目录。首次遇到方案 B 时，如果鲸鲸还没启动或刚装虚拟声卡，先按回车留待稍后。
3. 如果新装了 VB-CABLE，重启 Windows。进入声音设置，把输出改为 **CABLE Input**、输入改为 **CABLE Output**。微信麦克风使用系统默认设备，或者直接选 CABLE Output。
4. 打开鲸鲸和微信，确认鲸鲸连接的是要唱歌的微信账号。打开「插件市场 → 已安装」，找到 **Breezeblue 翻唱**，启用并确认完整权限。升级后也需要重新确认。旧唱歌和旧独立主动唱歌插件可以先停用。找不到卡片时，关掉鲸鲸，在安装器目录运行 `install.cmd -OnlyStep plugin -ForceSteps plugin`，检查所选鲸鲸目录，完成后重新启动。

## 2. 设置鲸鲸的唱歌音色

首次安装会进入 **方案 B**，引导你沿用鲸鲸现在说话的音色。已有可用参考音时，安装器会继续使用。

1. 启动微信和鲸鲸，确认内核、桥接和语音回复均可用。暂停其它电脑音频，保持微信窗口可用。
2. 安装器问「已准备好，现在开始方案 B？」时，输入 `Y`。它会向当前微信账号自己的「文件传输助手」发送测试语音，通过虚拟声卡录一小段，用于本机翻唱。
3. 看见「已使用鲸鲸当前语音生成参考音」就可以开始点歌。参考音保存在运行时的 `ref` 目录。

如果安装时跳过了参考音，先完成声卡设置并启动鲸鲸和微信，再在安装器目录打开终端执行以下命令。

```cmd
install.cmd -OnlyStep reference -UseInstalledVoice
```

## 3. 第一次点歌

1. 把你有权使用的歌曲放进运行时的 `data\songs`。例如把文件命名为 `样例曲.mp3`。
2. 在微信私聊里发「点歌 样例曲」。想区分同名歌时，可发「点歌 样例曲 - 歌手名」。用「点歌单」看队列。
3. 等鲸鲸完成整首翻唱。原版鲸鲸 4.1.8.2 会按停顿分成多条语音，核验上一条后继续发送。
4. 如果宿主支持长歌 WAV 附件选择，超过两分钟的歌会问你想要文件还是分段语音。点歌人可在原会话回复「发文件吧」或「分段发吧」。请以宿主的附件功能说明为准；原版 4.1.8.2 会直接发分段语音。

想再听成品可说「唱 样例曲」。想取消还在做的订单，可以说「取消点歌 样例曲」。如果提示结果不确定，先到微信核对语音条或附件。已有部分分段送达时，插件会停在回执不明确的位置，「唱 歌名」不会跳过它继续发送。

## 4. 从网易云「我喜欢的音乐」挑歌

在插件设置里将 `neteaseCookies` 指向你自己的本机 Cookie 文件。设置填文件路径即可。配置好后可以说「点歌 我喜欢的」或「从我喜欢里随便挑一首唱」。插件会尝试挑可下载、未唱过的曲目，并过滤带常见纯音乐或伴奏标记的曲目。

## 5. 开启闲时主动唱歌

打开插件卡片的「设置」，将 `proactiveEnabled` 设为 `true`。默认只在已绑定主人私聊里唱，空闲时间为 120 分钟，静默时段为本地时间 22:30 到次日 09:00。群聊需要把准确群会话 ID 加入 `proactiveGroupIds`。设置 `proactiveDryRun: true` 可以先看触发和渲染。想优先听网易云喜欢列表里的歌，可再开启 `proactiveLiked`。

具备 WAV 附件通道的宿主上，闲时主动唱的歌超过两分钟默认发整首 WAV。可以设置 `proactiveFollowup: true`，让鲸鲸在确认发出后再问你觉得好不好听。

## 6. 让鲸鲸给别人唱

1. 在插件设置中启用 `relaySingEnabled`，把目标私聊或群的准确会话 ID 填进 `relaySingWhitelist`。如果鲸鲸自身也启用了代发白名单，同步检查目标是否在名单中。
2. 用已绑定主人账号在自己的私聊发「去『目标群』唱《样例曲》」，或说「把刚才那首唱给另一位主人听」。
3. 核对预览里的歌名和收件会话，在同一个私聊内回复「发」确认，回复「算了」取消。确认有效期为十分钟。

群聊和私聊的会话 ID 可从鲸鲸本机的联系人缓存查看。以下命令只在本机运行：

```powershell
Invoke-RestMethod 'http://127.0.0.1:8787/api/wechat/contacts' |
  Select-Object -ExpandProperty items |
  Select-Object name, remark, wxid, isGroup
```

## 7. 常见故障

| 现象 | 先检查什么 |
| --- | --- |
| 点歌说找不到原曲 | 检查歌曲是否放进运行时的 `data\songs`，并让文件名与歌名一致。 |
| 方案 B 没录到声音 | 检查鲸鲸语音开关、绑定账户、微信前台、CABLE Input 和 CABLE Output。然后单独补做参考音步骤。 |
| 微信没出现语音条 | 确认微信窗口可用、目标会话名称可唯一匹配，以及录音设备为 CABLE Output。 |
| 回执说结果不确定 | 先去目标会话核对是否已有语音条或文件。长歌按已确认段数停住，避免重复发送。 |
| RTX 50 系列提示 CUDA 架构不支持 | 用 1.0.18 或更新安装器重跑依赖步骤。安装器会选择 cu128 并执行一次真实 GPU 算子检查。 |
| 长歌只看到分段语音 | 原版 4.1.8.2 的插件发送接口目前支持文字、TTS 语音和图片。整首 WAV 附件需要宿主提供附件发送能力。 |
