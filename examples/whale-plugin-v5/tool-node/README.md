# 示例工具（4 级 Node）

最小 4 级插件：在插件卡片里手动运行一次，统计输入文本的 Unicode 字符数，并读取宿主版本。

```json
{ "text": "深海鲸鱼" }
```

预期输出：

```json
{ "chars": 4, "appVersion": "4.3.0" }
```

## 设置

本示例没有可调项，所以清单不声明 `settingsSchema`（固定行为就是它的全部语义）。

## 权限

- 清单声明 `calls: ["status.read@1"]`：只读取宿主状态，无副作用。
- 4 级以当前 Windows 用户权限运行，**不是沙箱**；启用时需要用户确认完整系统权限。
- 插件自身的配置、运行、停用都在「插件市场 → 已安装 → 插件卡片」。
